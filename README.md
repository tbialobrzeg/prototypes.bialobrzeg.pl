# prototypes.bialobrzeg.pl

Zaakceptowane prototypy produktów pod `https://prototypes.bialobrzeg.pl/<slug>/`, jeden katalog na produkt.
Publikuje Lider produktu według skilla `product-publication` (Closed Loop Development); każdy zmienia tylko swój
katalog i swój wiersz w `index.html`. Pliki paczki prototypu się nie zmienia (zgodność z `checksums.sha256`);
wyszukiwarki pomija `robots.txt` w korzeniu, który prowadzi Lider procesu.
